# Paw Still Here

[pawstillhere.com](https://pawstillhere.com) · As long as they're remembered, they're still with us.（只要它们被记得，就一直和我们在一起。）

用 Three.js 做的在线宠物纪念馆：沿着石头路走进没有屋顶的大厅，正中是一棵纪念树（The Remembering Tree），三面墙是 A、B、C 三个区的照片墙，在夜空、流星和孔明灯下看看那些一直被记得的小家伙。

界面和场景里的文字目前只有英语，结构上支持多语言（见下面的「文字与多语言」）。本文档里引号中的按钮名是意思，界面上显示的是对应的英文。

## 启动

```bash
pnpm install
pnpm dev      # 本地开发
pnpm build    # 类型检查 + 打包到 dist/
pnpm preview  # 预览打包结果
```

## 操作

| 操作 | 桌面端 | 触屏 |
| --- | --- | --- |
| 移动 | WASD / 方向键上下，Shift 加速；或单击地面走过去 | 屏幕左侧按住拖动（摇杆出现在手指下，推到底是跑）；或轻点地面走过去 |
| 转视角 | 按住鼠标拖动，或 Q / E、方向键左右 | 在屏幕右侧滑动 |
| 缩放 | 滚轮 | 双指捏合 |
| 走进它的小院 | 点击相框 | 点击相框 |
| 放礼物 / 写信 | 点下方的图标 | 点下方的图标 |
| 读信 | 点石阶上的那摞信 | 点石阶上的那摞信 |
| 在小院里坐一会儿 | 点长椅 | 点长椅 |
| 离开小院 | 走出院子的缺口、Esc 或「回到相框前」 | 走出院子的缺口或「回到相框前」 |

底部按钮可以一键传送到入口（Gate）、码头（Dock）、篝火（Fire）、孔明灯平台（Lanterns）、大厅（Lobby），也可以查找宠物（名字、品种或区，如 `luna`、`poodle`、`a`、`section b`，不区分大小写）。大厅接待台和台上的留言簿可以点击，纪念树两侧的沙发点一下可以坐下。

### 河灯

入口步道中途有一条河，步道在这里变成一座石拱桥。桥头靠入口一侧有个小码头，点击码头上摆着河灯的木台，就能放下一盏河灯，看它在水面上亮着顺水漂开。可以直接放，也可以先搜一只宠物，灯上就会写着它的名字。在它的小院里点「为它放河灯」会直接来到码头，名字已经选好（也可以改掉）。

### 篝火烧信

过了桥再往前，步道左侧有一块空地，中间是一堆篝火，围着几个树桩凳。点击火堆，选一只宠物，写一封信投进火里，信纸会卷曲、烧尽，化成一串火星升上夜空。烧掉的信不保存内容，只记下给它烧过一封信；想留下的信请放在它的小院里。在它的小院里点「给它烧一封信」会直接来到篝火旁。

### 孔明灯

篝火对面、步道右侧有一块圆形石台：一张矮木桌上摆着几盏还没点的纸灯，后面的木架上挂着三盏亮着的灯。点击桌子，写一句话，灯就从桌面上升起，带着这句话飘上夜空。也可以选一只宠物：没写字时灯上写它的名字；什么都不填，灯上是默认的那句短标语。孔明灯只记总数，不记内容和写给谁。

三件事里只有烧信必须选一只宠物、必须写内容；河灯和孔明灯选不选都可以。

### 其他访客

馆里会有几位其他访客慢慢走动：在照片墙前、纪念树前、码头、河边和孔明灯平台站一会儿，在沙发、篝火旁的树桩凳上坐一会儿，逛几处之后从入口离开，过一阵再换一个人进来。他们只是在场，不放灯、不烧信，也不读写任何数据；人和人之间可以互相穿过。右上角的「访客：显示 / 隐藏」可以切换成独自参观，选择会记住。

现在这些访客是本地模拟的。访客的数据来源（`VisitorSource`）和绘制（`Crowd`）是分开的：以后接后端时，只需再写一个从网络接收状态的 `VisitorSource`，替换 `main.ts` 里创建 `SimulatedVisitors` 的那一行，绘制部分不用改。

### 它的小院

点击照片墙上任意一张相框，画面暗一下，就走进了这只宠物专属的小院：一圈弧形石墙围着的露天空地，正对入口是它的石柱，上面有照片、名字、日期和主人的寄语，柱脚三级石阶上摆着大家留下的东西。在这里可以照常走动，为它放下花、蜡烛、零食、玩具，或者写一封信；入口内侧有张长椅，点一下可以坐下来陪它一会儿。走出院子的缺口就回到刚才那张相框前；石柱上名字下面刻着它的地址（如 `Floor 1 · Section B · No. 12`）。有人为它放过花或点过蜡烛，照片墙上它相框下的小石台也会留下一枝花、一点烛光。

每个区两端有铭牌写着区名和格号范围（如 `Section A · 1–60`），电梯旁挂着本层的总览图。进门左手是 A 区，正对面是 B 区，右手是 C 区；以后展区开放，字母往后接着排。

全馆只有这一座小院，建在主场景之外很远的地方，进去时换成那只宠物的内容；院子里没有其他访客。

## 常见修改

### 添加自己的宠物

编辑 `src/data/pets.ts` 顶部的 `CUSTOM_PETS`。宠物按顺序住进照片墙：先填 A 区，满了到 B 区，排在前面的格号也靠前：

```ts
export const CUSTOM_PETS = [
  {
    name: 'Doudou',
    species: 'dog',           // cat | dog | rabbit | hamster | bird
    breed: 'Corgi',
    birthDate: '2012-03-01',
    passedDate: '2025-06-18',
    photoUrl: '/photos/doudou.jpg',
    message: 'Your spot on the sofa is still yours.',
  },
];
```

### 替换照片

把图片放进 `public/photos/`，然后在宠物数据里填 `photoUrl: '/photos/文件名.jpg'`。照片会被裁成正方形。没有 `photoUrl` 的宠物使用程序生成的卡通画像。使用其他域名的图片时，对方服务器需要允许跨域（CORS）。

### 相册（多张照片）

除了照片墙上那一张，每只宠物还可以有几张照片，挂在它小院的弧墙内侧。在宠物数据里填 `photos: ['/photos/文件名-2.jpg', '/photos/文件名-3.jpg']`，最多挂 6 张（`config.ts` 里 `space.album.angles` 有几个方向就挂几张），多出来的不显示。只填了 `photoUrl`、没填 `photos` 的宠物墙上不挂相册。示例宠物每只有两到四张程序画的占位画像。

### 替换音乐

把音乐文件放到 `public/audio/bgm.mp3`，会自动循环播放。没有这个文件时，程序会用 WebAudio 现场合成一段舒缓的环境音乐，所以不放文件也不会报错。

### 调整场景

`src/config.ts` 里可以改大厅的尺寸、照片墙的行列数和相框大小、小院的尺寸和每类礼物最多摆出的件数、河流的位置宽度流速和河灯数量、篝火的位置和烧信时长、孔明灯平台的位置和大小、小人的身高速度颜色、镜头的距离和俯仰范围、模拟访客的人数速度停留时长和衣服颜色、宠物数量、星星和孔明灯数量、流星间隔、主要颜色等。界面与场景里的文字都在 `src/i18n/en.ts`。

### 文字与多语言

访客能看到的字都在 `src/i18n/` 里，其余代码只用 `STR`，不直接写文字：

- `en.ts` 是完整的一份：品牌名和标语、界面、场景里的字、物种的显示名、地址的写法、示例宠物的名字品种寄语、页面信息（`meta`），以及这门语言的字体和字间距（`style`）。
- 加一种语言：照着 `en.ts` 写一个文件（比如 `zh.ts`，类型标成 `Strings`），在 `index.ts` 的 `LOCALES` 里登记。缺一条就编译不过。现在没有切换语言的入口，用哪种语言由 `index.ts` 里的 `LOCALE` 决定。
- `sample` 里各个列表的条数不要改：示例宠物是用固定的随机数从里面挑的。
- 数据里不存文字：物种是 `cat / dog / rabbit / hamster / bird`，区是 `A / B / C`，显示名从 `STR` 取。
- 品牌的说法：说「记得」「还在这里」，不说「去了星星上」「离开」「逝去」；日期只写起止年月日。

宠物总数上限是 100（照片图集是 10 × 10 格）。需要更多时，调大 `src/world/Batches.ts` 里 `PhotoBatch` 的图集尺寸。

### 接入后端

礼物、信、留言簿，以及放河灯、烧信的记录，读写都封装在 `src/data/store.ts`，目前存在浏览器的 localStorage 里（键名 `jinian:v2`，改品牌名时没有动，改了会丢掉已有数据），所以每位访客只能看到自己放的东西。接后端时只需要替换这个文件里的实现。

旧版本存下的数据（键名 `jinian:v1`，只有花数、蜡烛数和留言）会在第一次打开时自动转换成新格式，原数据保留不动。

## 画质

右上角可以切换画质。「低」会关闭辉光后期和月光阴影，并降低渲染分辨率；触屏设备默认使用低画质。
