# 星光宠物纪念馆

用 Three.js 做的在线宠物纪念馆：沿着石头路走进没有屋顶的大厅，正中是一棵纪念树，三面墙是带编号的照片墙，在夜空、流星和孔明灯下看看那些曾经陪伴过我们的小家伙。

## 启动

```bash
pnpm install
pnpm dev      # 本地开发
pnpm build    # 类型检查 + 打包到 dist/
pnpm preview  # 预览打包结果
```

## 操作

| 操作 | 桌面端 | 触屏 |
| --- | --- | --- |
| 移动 | WASD / 方向键上下，Shift 加速；或单击地面走过去 | 屏幕左侧按住拖动（摇杆出现在手指下，推到底是跑）；或轻点地面走过去 |
| 转视角 | 按住鼠标拖动，或 Q / E、方向键左右 | 在屏幕右侧滑动 |
| 缩放 | 滚轮 | 双指捏合 |
| 走进它的小院 | 点击相框 | 点击相框 |
| 放礼物 / 写信 | 点下方的图标 | 点下方的图标 |
| 读信 | 点石阶上的那摞信 | 点石阶上的那摞信 |
| 在小院里坐一会儿 | 点长椅 | 点长椅 |
| 离开小院 | 走出院子的缺口、Esc 或「回到相框前」 | 走出院子的缺口或「回到相框前」 |

底部按钮可以一键传送到入口、河边、篝火、大厅，也可以查找宠物（名字、品种或墙号）、放孔明灯。大厅接待台和台上的留言簿可以点击，纪念树两侧的沙发点一下可以坐下。

### 河灯

入口步道中途有一条河，步道在这里变成一座石拱桥。桥头靠入口一侧有个小码头，点击码头上摆着河灯的木台，选一只宠物，就能放下一盏写着它名字的河灯，看它顺着河水漂远。在它的小院里点「为它放河灯」会直接来到码头，名字已经选好。

### 篝火烧信

过了桥再往前，步道左侧有一块空地，中间是一堆篝火，围着几个树桩凳。点击火堆，选一只宠物，写一封信投进火里，信纸会卷曲、烧尽，化成一串火星升上夜空。烧掉的信不保存内容，只记下给它烧过一封信；想留下的信请放在它的小院里。在它的小院里点「给它烧一封信」会直接来到篝火旁。

### 其他访客

馆里会有几位其他访客慢慢走动：在照片墙前、纪念树前、码头和河边站一会儿，在沙发、篝火旁的树桩凳上坐一会儿，逛几处之后从入口离开，过一阵再换一个人进来。他们只是在场，不放灯、不烧信，也不读写任何数据；人和人之间可以互相穿过。右上角的「访客：显示 / 隐藏」可以切换成独自参观，选择会记住。

现在这些访客是本地模拟的。访客的数据来源（`VisitorSource`）和绘制（`Crowd`）是分开的：以后接后端时，只需再写一个从网络接收状态的 `VisitorSource`，替换 `main.ts` 里创建 `SimulatedVisitors` 的那一行，绘制部分不用改。

### 它的小院

点击照片墙上任意一张相框，画面暗一下，就走进了这只宠物专属的小院：一圈弧形石墙围着的露天空地，正对入口是它的石柱，上面有照片、名字、日期和主人的寄语，柱脚三级石阶上摆着大家留下的东西。在这里可以照常走动，为它放下花、蜡烛、零食、玩具，或者写一封信；入口内侧有张长椅，点一下可以坐下来陪它一会儿。走出院子的缺口就回到刚才那张相框前。

全馆只有这一座小院，建在主场景之外很远的地方，进去时换成那只宠物的内容；院子里没有其他访客。

```
src/
  config.ts          尺寸、数量、颜色等可调参数
  strings.ts         所有文案
  main.ts            入口：渲染器、后期、主循环、各系统的连接
  data/
    pets.ts          宠物数据（示例数据生成 + 自定义宠物）
    store.ts         数据层：礼物、信、留言簿（localStorage）
  world/
    World.ts         场景总管：灯光、碰撞体、可交互物体、搭建步骤
    Kit.ts           积木工具箱（方块 / 圆柱 / 圆锥 / 球，全部实例化渲染）
    Batches.ts       照片图集与名牌图集
    Sky.ts           天穹、星星、月亮、流星、孔明灯
    Outdoor.ts       石头路、树、路灯、花草、萤火虫
    River.ts         河流：河床、水面、石拱桥、码头、河灯
    Bonfire.ts       篝火空地：火焰、火星、树桩凳、烧信动画
    Hall.ts          大厅：墙、串灯、沙发、接待台、电梯门、后墙的石门
    Tree.ts          大厅正中的纪念树
    Gallery.ts       三面编号照片墙：相框、石台、名牌和格号
    Space.ts         宠物的专属小院：弧墙、石柱、石阶上的礼物、长椅
    Avatar.ts        低多边形小人：模型、走路动画（实例化渲染）
    gifts.ts         礼物的小模型：花、蜡烛、零食、玩具、信
    parts.ts         通用部件：拱门墙、沙发、长椅、盆栽、壁灯
    textures.ts      用 Canvas 生成的纹理与宠物占位画像
  systems/
    Visitors.ts      其他访客：数据来源接口（VisitorSource）与绘制（Crowd）
    SimulatedVisitors.ts  本地模拟的访客：路点图、停留点、进出场
    Marker.ts        点击地面后标出目的地的光圈
    Player.ts        第三人称：小人移动与碰撞、跟随镜头与避障、小院的圆形边界、坐下
    Interaction.ts   悬停与点击拾取
    Guide.ts         地面光点指引（找宠物、去码头、去篝火）
    AudioSystem.ts   环境音
  ui/
    UI.ts            界面逻辑
    style.css        界面样式
```

## 常见修改

### 添加自己的宠物

编辑 `src/data/pets.ts` 顶部的 `CUSTOM_PETS`。宠物按顺序住进照片墙：先填 1 号墙，满了到 2 号墙，排在前面的格号也靠前：

```ts
export const CUSTOM_PETS = [
  {
    name: '豆豆',
    species: '狗',            // 猫 | 狗 | 兔子 | 仓鼠 | 鸟
    breed: '柯基',
    birthDate: '2012-03-01',
    passedDate: '2025-06-18',
    photoUrl: '/photos/doudou.jpg',
    message: '下辈子还做我的小狗。',
  },
];
```

### 替换照片

把图片放进 `public/photos/`，然后在宠物数据里填 `photoUrl: '/photos/文件名.jpg'`。照片会被裁成正方形。没有 `photoUrl` 的宠物使用程序生成的卡通画像。使用其他域名的图片时，对方服务器需要允许跨域（CORS）。

### 替换音乐

把音乐文件放到 `public/audio/bgm.mp3`，会自动循环播放。没有这个文件时，程序会用 WebAudio 现场合成一段舒缓的环境音乐，所以不放文件也不会报错。

### 调整场景

`src/config.ts` 里可以改纪念馆名字、大厅的尺寸、照片墙的行列数和相框大小、小院的尺寸和每类礼物最多摆出的件数、河流的位置宽度流速和河灯数量、篝火的位置和烧信时长、小人的身高速度颜色、镜头的距离和俯仰范围、模拟访客的人数速度停留时长和衣服颜色、宠物数量、星星和孔明灯数量、流星间隔、主要颜色等。界面与场景里的文字都在 `src/strings.ts`。

宠物总数上限是 100（照片图集是 10 × 10 格）。需要更多时，调大 `src/world/Batches.ts` 里 `PhotoBatch` 的图集尺寸。

### 接入后端

礼物、信、留言簿，以及放河灯、烧信的记录，读写都封装在 `src/data/store.ts`，目前存在浏览器的 localStorage 里（键名 `jinian:v2`），所以每位访客只能看到自己放的东西。接后端时只需要替换这个文件里的实现。

旧版本存下的数据（键名 `jinian:v1`，只有花数、蜡烛数和留言）会在第一次打开时自动转换成新格式，原数据保留不动。

## 画质

右上角可以切换画质。「低」会关闭辉光后期和月光阴影，并降低渲染分辨率；触屏设备默认使用低画质。
